The first preview of the Contr app for Linux: a GNOME app for the containers, images, volumes, networks, Compose
projects and Kubernetes cluster of the container engine on your computer. It works with the `contrd` daemon of
[Contr v0.1.0-alpha.2](https://github.com/contr-hq/contr/releases/tag/v0.1.0-alpha.2), which manages the engine. It is
still an early build; expect rough edges.

## What it does

**Containers**

- Containers grouped by Compose project, with start, stop, restart and delete, and a notification when one exits with
  an error.
- Each container's logs with search and timestamps, its settings and environment, a terminal, and live CPU, memory,
  network and disk use.
- A Run dialog that publishes the ports an image exposes on 127.0.0.1, choosing ports that are free.

**Images, volumes and networks**

- Images sorted by whether a container uses them, pulls with progress for every layer, tag and push with the
  credentials `docker login` stored, and cleanup of what no container uses.
- Volumes and networks with the containers that use them; containers can join and leave networks.

**Compose and Kubernetes**

- Compose projects with their services and logs, and Up, Pull, Restart, Stop and Down.
- A single-node Kubernetes cluster (k3s) on the engine: turn it on, follow its start-up, make it kubectl's current
  context, import local images into it, and reset it.

**Setup, troubleshooting and settings**

- First-run setup shows the engine Contr found, and offers to install Docker Engine or give you access to it.
- Troubleshoot runs Contr's checks, offers its fixes, shows the daemon's and the engine's logs from the systemd
  journal, saves a diagnostics bundle for support, and cleans up or resets.
- Preferences for starting at login, notifications, update checks and the proxy the update check uses. Docker Engine
  on Linux keeps its own proxy, certificate and registry mirror settings; Contr does not change them.
- A banner announces new releases. The daemon checks GitHub once a day; turn this off in Preferences → Updates.

## Install

This preview is in the `testing` channel of the signed repositories at <https://contr-hq.github.io/contr-packages/>.
Installing `contr` also installs `contr-daemon` (0.1.0~alpha.2 or newer).

Ubuntu:

```sh
sudo curl -fsSo /usr/share/keyrings/contr.gpg https://contr-hq.github.io/contr-packages/contr.gpg
echo "deb [signed-by=/usr/share/keyrings/contr.gpg] https://contr-hq.github.io/contr-packages/apt testing main" |
  sudo tee /etc/apt/sources.list.d/contr.list
sudo apt update && sudo apt install contr
```

Fedora:

```sh
sudo curl -fsSo /etc/yum.repos.d/contr-testing.repo https://contr-hq.github.io/contr-packages/rpm/contr-testing.repo
sudo dnf install contr
```

| File | Contents |

Installing a downloaded package by itself also needs the `contr-daemon` package from the repositories above or from
the [Contr v0.1.0-alpha.2](https://github.com/contr-hq/contr/releases/tag/v0.1.0-alpha.2) release.

## Verifying downloads

Every package carries a GitHub build attestation (`gh attestation verify <file> --repo contr-hq/contr-linux`), and
`SHA256SUMS` is signed with the project's key at
<https://contr-hq.github.io/contr-packages/checksums/contr-linux/v0.1.0-alpha.2/>. See
[Verifying downloads](https://github.com/contr-hq/contr/blob/main/docs/verifying.md) and the
[Code signing policy](https://github.com/contr-hq/contr/blob/main/docs/code-signing-policy.md).

## Known limitations

- Builds are for x64 only.
- The packages are built for Ubuntu 26.04 and Fedora 44, and need GTK 4.20, libadwaita 1.8 and VTE 0.76 or newer.
- GNOME shows the tray icon only with the AppIndicator extension, which Ubuntu turns on.
- Setup shows only the engine the daemon manages; choosing another engine on the computer is not available yet.
