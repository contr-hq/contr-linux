The second preview of the Contr app for Linux: a GNOME app for the containers, images, volumes, networks, Compose
projects and Kubernetes cluster of the container engine on your computer. It works with the `contrd` daemon of
[Contr v0.1.0-alpha.3](https://github.com/contr-hq/contr/releases/tag/v0.1.0-alpha.3), which manages the engine. It is
still an early build; expect rough edges.

## What's new

**Work that keeps going**

- Pulls, pushes, Compose actions, copying images into Kubernetes, fixes and diagnostics bundles run in the daemon.
  They keep going when you switch sections, leave a container's or a project's page, close the window or quit Contr.
  A reopened page, or Contr started again, shows the work that is still running.
- **Activity** at the top of the sidebar lists running and recent work, with its progress. From there you can:
  - cancel work where the daemon allows it;
  - run the fixes a failure offers;
  - save a finished diagnostics bundle.

  Work started with the `contr` command line shows there too.
- Every result appears in one place, whichever section is open. A desktop notification tells you when work finishes
  while Contr's window isn't in front; it is now on by default, and Preferences turns it off.
- Starting the same pull twice joins the first one, and a project's Compose actions can't overlap.
- Cancel in the Run dialog now stops the pull it started, and a container's actions finish even after you leave its
  page.

**A new look**

- A darker, muted slate theme and app icon.

This version needs `contr-daemon` 0.1.0~alpha.3 or newer, which the packages install.

## Install

This preview is in the `testing` channel of the signed repositories at <https://contr-hq.github.io/contr-packages/>.
Installing `contr` also installs `contr-daemon` (0.1.0~alpha.3 or newer).

Ubuntu:

```sh
sudo curl -fsSo /usr/share/keyrings/contr.gpg https://contr-hq.github.io/contr-packages/contr.gpg
echo "deb [signed-by=/usr/share/keyrings/contr.gpg] https://contr-hq.github.io/contr-packages/apt testing main" |
  sudo tee /etc/apt/sources.list.d/contr.list
sudo apt update && sudo apt install contr
```

Fedora:

```sh
sudo curl -fsSo /etc/yum.repos.d/contr-testing.repo https://contr-hq.github.io/contr-packages/rpm/contr-testing.repo
sudo dnf install contr
```

If you already have 0.1.0-alpha.2, `sudo apt upgrade` or `sudo dnf upgrade` installs both new packages. Then restart
the daemon with `systemctl --user restart contrd`, or sign out and back in.

## Verifying downloads

Every package carries a GitHub build attestation (`gh attestation verify <file> --repo contr-hq/contr-linux`), and
`SHA256SUMS` is signed with the project's key at
<https://contr-hq.github.io/contr-packages/checksums/contr-linux/v0.1.0-alpha.3/>. See
[Verifying downloads](https://github.com/contr-hq/contr/blob/main/docs/verifying.md) and the
[Code signing policy](https://github.com/contr-hq/contr/blob/main/docs/code-signing-policy.md).

## Known limitations

- Builds are for x64 only.
- The packages are built for Ubuntu 26.04 and Fedora 44, and need GTK 4.20, libadwaita 1.8 and VTE 0.76 or newer.
- GNOME shows the tray icon only with the AppIndicator extension, which Ubuntu turns on.
- Setup shows only the engine the daemon manages; choosing another engine on the computer is not available yet.
